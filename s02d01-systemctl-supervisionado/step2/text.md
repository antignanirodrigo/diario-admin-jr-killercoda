## Ação: Escreva uma "mensagem de aprovação" fictícia antes de reiniciar.

praticar o hábito de registrar a aprovação ANTES de agir é o que separa "eu reiniciei e depois expliquei" de "fui autorizado e documentei antes" — a ordem importa tanto quanto a ação em si.

```bash
# não é comando de shell — é o registro escrito
# ex: "Aprovado por: Sênior. Ação: reiniciar nginx. Horário: 10:23."
```

**Resultado esperado:** uma linha com quem aprovou, o que foi aprovado, e o horário — o mesmo formato que apareceu na prancha de hoje.

> **Cilada comum:** pular esse passo achando que é "só formalidade" — é exatamente o registro de aprovação que protege você se algo der errado depois do restart.
