## Ação: Escreva, numa frase, a diferença entre "estar no grupo sudo" e "estar como root agora".

conseguir explicar com suas próprias palavras é o teste real de que você entendeu — decorar o comando sem entender o conceito não segura sob pressão num chamado de verdade.

```bash
# não é comando de shell — é registro escrito, uma frase só
# ex: "Grupo sudo autoriza; root ativo é quando eu digito sudo antes de um comando."
```

**Resultado esperado:** uma frase que outra pessoa entenderia sem precisar perguntar nada de volta.

> **Cilada comum:** escrever uma frase tecnicamente correta mas cheia de jargão que nem você mesmo reconhece de cabeça fria depois. Se soa complicado pra você, vai soar pior pra quem ler depois.
